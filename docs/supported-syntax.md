# Supported Verilog subset (0.4.0)

| Construct                                                                                                         | Support                                                                                                                                                |
| ----------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| ANSI modules, scalar/vector input/output, optional wire and inherited widths                                      | Yes; up to 64 definitions per document                                                                                                                 |
| Ascending/descending constant packed widths and fixed bit/part selection                                          | Yes                                                                                                                                                    |
| Internal wires and continuous assignments                                                                         | One driver per declared non-input signal                                                                                                               |
| Unsigned decimal and sized binary/octal/decimal/hex literals                                                      | Yes, with digit/overflow validation                                                                                                                    |
| Parentheses and binary `+ - * &                                                                                   | ^`                                                                                                                                                     | Yes; unsafe precedence-changing token edits are refused |
| Ternary mux                                                                                                       | Yes; the graph connects scalar selectors, source vector selectors use nonzero truth and receive a warning                                              |
| Concatenation `{high, low}`                                                                                       | 1–64 source parts; constructor joins 2–64 declared signals; literals inside concatenations must be explicitly sized                                    |
| Bus splitting                                                                                                     | Constructor generates up to 64 equal fixed slices and individually named result wires                                                                  |
| Named-port module instances                                                                                       | Definitions in the same document; each input/output connected exactly once, outputs to distinct named non-input nets                                   |
| Other explicitly shared files                                                                                     | Explicit import copies the selected module and dependencies; no implicit filesystem scan or live linking                                               |
| Operator/literal/range/scalar-selector editing                                                                    | Exact UTF-16 source spans, including child module inputs/bodies                                                                                        |
| Component creation, connection, tie-offs, removal                                                                 | Supported through guarded construction transactions                                                                                                    |
| Copy/paste/duplicate                                                                                              | Up to 50 named items, remapped internal nets, explicit interface ports and instances; external names must resolve                                      |
| Diagnostics                                                                                                       | Unused/undriven signals, width extension/truncation, vector selectors; source errors remain separate                                                   |
| Simulation                                                                                                        | Local, unsigned zero-delay combinational evaluator, context-sized arithmetic, bitwise unknown masks, mux merging, slices, concatenations and hierarchy |
| Multiple drivers, undeclared names, recursive hierarchy and combinational cycles                                  | Rejected                                                                                                                                               |
| `reg`, `always`, clocks, delays, events, functions, tasks, macros, parameters, generate                           | Unsupported                                                                                                                                            |
| Signed values, unsized based literals, source x/z literals, unary operators, variable/indexed slices, replication | Unsupported                                                                                                                                            |
| Positional/parameterized instances, inout, black boxes, assignments to slices                                     | Unsupported                                                                                                                                            |

A document is limited to 1 million UTF-16 units, 32768 tokens and 64 modules; each module has at most 4096 tokens and expressions have at most 128 recursive levels. Expanded hierarchy is limited to 256 instances and 32 levels. Instance cycle checks conservatively treat each output as dependent on all inputs, so independent-port feedback patterns can be refused. One unsupported definition prevents a complete projection; the last valid graph remains visible.

The graph uses Verilog unsigned assignment context for arithmetic/mux result widths. Diagnostics do not rewrite widths. Constants exceeding their explicit width are refused. Simulator values are limited to 4096 bits and the expanded circuit to 512 signals; undriven nets are represented as unknown rather than distinguishing `z`. Input vectors may contain unknown binary bits. This is not a full four-state, timed HDL simulator. The waveform UI retains 64 sampled vectors and at most 16 watched signals; newly added traces have no historical sample until the next evaluation.

Structural changes preserve surrounding source and comments. Shared wire declarations and comment-bearing spans require source edits for destructive changes. Ports cannot be removed through the graph. Adding/changing a child interface must leave all existing instances valid. Removing an instance leaves its output wires declared and visibly undriven. Copies preserve supported expressions and reject statement/comment injection. Nested expressions need named results to be shared/copied individually.

The extension replays construction proofs against the exact version/hash before one native WorkspaceEdit. Pending Undo/Redo is local to a batch; after synchronization use native editor Undo. Navigation/import/simulation do not bypass ACK/conflict locks. Recovery restore is manual. IDs use module/structural paths and kind; committing removal discards the old active-module identity while preserving other module views.
