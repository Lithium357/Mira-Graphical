# Mira Graphical companion

Build from the repository root with `pnpm install` and `pnpm build`. Start the standalone app for your workspace, then launch the extension with the root VS Code debug configuration (F5). In the Extension Development Host, open a `.v` file and run **RTL Graph: Open Current Module**. Unsaved changes synchronize after 15 seconds. See the repository README for scope, setup, security, demo and tests.

Commands: Open Current Module; Connect/Disconnect; Show Sync Status. All use the `RTL Graph:` command prefix. The extension never saves source files automatically.
